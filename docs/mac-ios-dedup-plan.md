# Mac / iOS 去重计划

2026-11-05，只读分析，没有编译也没有运行。两个 app 的各块都已对比完；标"未核实"的是子 agent 读到、没有复查的。

## 结论

- 能共享的大头**早就共享了**：分屏几何、拖放落点、分隔线、状态色、窗口侧栏、语音、设置面板、浏览器标签、搜索状态都在 Modules 里，两边调的是同一份。两个大的宿主文件不是互相的拷贝，大部分行是 AppKit / UIKit 的视图、手势、键盘和输入法。
- 剩下的是很多处小的重复判断：窗口操作的对话框（约 5 份）、列 tmux session（4 种写法）、终端尺寸推送、pane 菜单（4 份手写清单）、颜色和字体小工具。
- 能删的大约 **700 到 850 行**，不多。更值钱的是两边不再各写各的，以及顺手修掉下面这些问题。

## 顺手能修的问题

1. **开着会话改字号后，iOS 分屏格子还按旧的字符尺寸排**：iOS 只在第一次学字符大小，Mac 早修过同一个问题。要真机确认。
2. **iPhone 底部窗口 tab 不显示"已完成未查看"的绿勾**：它自己抄了一份状态映射，漏了这个状态。
3. **iPad 新建窗口只能手打路径**，iPhone 那个能浏览远端目录。
4. **文案分叉**：关闭窗口、Flatten（一边写 Bento 一边写 BentoTerm）、"落在哪"的提示，两端说法不同。
5. **session 状态点的优先级不一致**：Mac 是 等待 > 已完成 > 进行中，共享逻辑是 等待 > 进行中 > 已完成。
6. **Mac 连远端 tmux 时，⌘ 点路径预览可能读的是本机磁盘**（未核实，先复现）。
7. **iOS 新建 session 名写死成 "bento"，没走统一的命名清洗**（未核实）。
8. **iOS 字体映射重复，默认还是已经从包里删掉的 Maple，也没有 JetBrains**（未核实）。
9. **Mac 搜索条刚打完字马上点上一个/下一个，搜的是旧词**（未核实）。
10. 小事：iOS 快捷键条方向键写死 `CSI A..D`，没管 application cursor 模式；iOS 列 session 时丢了 stderr，没法告诉用户"没装 tmux"。

## 不做

两边标题栏视图、分隔线和拖放浮层视图、pane 增删同步、两个 surface 本身、输出喂数据的方式（Mac 在 ioQueue 解析，iOS 在主线程按帧限时，故意不同）、session 选择器和首次启动。这些合并没收益或风险高。

## 另外

- 共享模块里有几样两个 app 都没直接引用：`ArchitectureDiagramView`、`BentoUserAgent`、`PanelKit`、`MonospacedFonts`、`PanelFigure`，删前要确认 Panels 内部有没有用。
- Mac 的命令面板基本是纯逻辑，以后 iPad 想要 ⌘P 可以搬进共享模块，现在搬省不了行数。
